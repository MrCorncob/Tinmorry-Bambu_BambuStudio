# Tinmorry Filament Profiles for Bambu Studio

*[Tiếng Việt](README.vi.md) | [中文](README.zh.md)*

Forked from [TINMORRY/Tinmorry-Bambu_BambuStudio](https://github.com/TINMORRY/Tinmorry-Bambu_BambuStudio).

Custom Bambu Studio filament presets for **TINMORRY** filaments, packaged as `.bbsflmt` bundles and organized by Bambu Lab printer model.

## ⚠️ Caution — read before downloading or using

- Profiles marked **Derived** in the table below are **not original TINMORRY exports**. They were generated by merging TINMORRY's older per-printer profile data onto another bundle's machine parameters (see `CLAUDE.md` / `REFERENCES.md`) and have **not** been print-validated by TINMORRY.
- Before printing with any **Derived** profile, cross-check nozzle, bed/plate, and chamber temperatures against the filament's actual spool label or manufacturer datasheet — **especially PA-CF and PAHT-CF on X2D**, which inherited PETG CF's temperature range rather than their own (notably lower than PA-CF/PAHT-CF typically require).
- Use a hardened/abrasion-resistant nozzle for any CF- or GF-filled filament (PETG-CF, PLA-CF, PET-CF, PC GF, TPU GF, PA-CF, PAHT-CF, PP-CF).
- Run a small test print and supervise the first layers before committing to a full print, particularly on printers without an enclosure (A1, A1 mini, A2L).
- **A1's PC GF profile is a real oddity worth flagging**: Bambu Studio itself ships a system profile for PC-GF on the (open-frame, no enclosure) A1, so it's included here as direct evidence — but that doesn't mean ABS/ASA are also fine on A1, and this repo deliberately does not generate those for A1. If you print PC GF on an open A1, ventilate the area and expect more warping than on an enclosed printer.
- These profiles are provided as-is with no warranty. You are responsible for verifying a profile is safe for your printer and filament before use.

## Repository layout

Each top-level folder corresponds to a printer model (as reported in each profile's `compatible_printers` field). `X2D` additionally nests profiles under a `0.4mm` nozzle folder.

```
A1/       Bambu Lab A1, 0.4mm nozzle
A1mini/   Bambu Lab A1 mini, 0.4mm nozzle
A2L/      Bambu Lab A2L, 0.4mm nozzle
H2C/      Bambu Lab H2C, 0.4mm nozzle
H2D/      Bambu Lab H2D, 0.4mm nozzle
H2S/      Bambu Lab H2S, 0.4mm nozzle
P1S/      Bambu Lab P1S, 0.4mm nozzle
P2S/      Bambu Lab P2S, 0.4mm nozzle
X2D/0.4mm/  Bambu Lab X2D, 0.4mm nozzle
```

## Available profiles

Click a printer below to see its filaments. Each row's **Download** link goes straight to the `.bbsflmt` file — right-click it and choose "Save Link As" (no need to clone this repo or browse GitHub).

- **Original** = a real TINMORRY export.
- **Derived** = not from TINMORRY directly; generated from TINMORRY's older per-printer data by the scripts in this repo (see `CLAUDE.md`). Read the **⚠️ Caution** section above before using a Derived profile, especially PA-CF/PAHT-CF on X2D.

Some filaments (PETG GF, PETG Marble, PETG Metallic, TPU 95A) ship a single bundle under `X2D/0.4mm/` that also covers the P2S printer.

## Installing a profile

1. In Bambu Studio, go to **File → Import → Import Configs**.
2. Select the `.bbsflmt` file for the filament/printer combination you want.
3. The filament preset will appear under the matching printer in the filament dropdown, under the `TINMORRY` vendor.

## File format

Each `.bbsflmt` file is a zip archive (Bambu Studio's filament config bundle format) containing:

- `bundle_structure.json` — bundle metadata: bundle id, the Bambu Studio version it was exported from, the filament name, and the vendor/profile-path mapping.
- `TINMORRY/<filament> @<printer> 0.4 nozzle.json` — one filament settings profile per compatible printer, with the full set of Bambu Studio filament parameters (temperatures, cooling, flow, retraction, etc.).

See [REFERENCES.md](REFERENCES.md) for a full inventory of bundles and their metadata.

## Known quirks

- A few filenames contain unusual characters carried over from the original export (e.g. a full-width comma in `H2D/TINMORRY PLA Matte，.bbsflmt`, a backtick in `` P2S/TINMORRY PP-CF `.bbsflmt ``). These are cosmetic and don't affect import.
